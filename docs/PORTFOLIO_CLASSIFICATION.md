# 포트폴리오 분류 규칙

작품 분류와 표시 순서는 아래 우선순위를 따른다.

1. PPT의 상세 분류 슬라이드 소속
2. PPT에서 작품이 등장하는 순서
3. 작품 내용의 연속성
4. 색감 유사성

추가 규칙:

- 개요 슬라이드와 상세 슬라이드에 같은 작품이 등장하면 상세 슬라이드 소속을 사용한다.
- 같은 디자인이 다른 크기나 크롭으로 중복 저장됐으면 상세 슬라이드의 파일만 작품으로 유지한다.
- 원본 뷰어의 작품 배열은 PPT 순서를 변경하지 않는다.
- 그룹을 좌우로 이동할 때만 PPT에서 추출한 대표 이미지 위치로 진입한다.
- 비젠티브 마스코트는 최상위 대분류에 항상 유지하고, 관련 작품은 AI 모델 그룹에도 포함한다.

현재 확인된 예외:

- `25`: 개요 슬라이드에도 나오지만 상세 분류인 아웃도어에 배정한다.
- `24`와 `46`: 동일한 디자인의 다른 크기·크롭 사본이므로 상세 슬라이드의 `46`만 유지한다.
- 카드뉴스 작품 순서는 파일 번호가 아니라 PPT의 시각적 읽기 순서를 사용한다: `87, 86, 85, 88 → 89–92 → 84, 83, 82 → 93–96`.
- 카드뉴스 순서는 PPTX 추출 시 21–24페이지의 위→아래, 왼쪽→오른쪽 배치로 자동 생성한다.
- 카드뉴스 대표 이미지: PPT 매니페스트가 선택한 `87`. 대표 진입 위치일 뿐 작품 배열의 첫 항목으로 이동시키지 않는다.
