## 현재 홈 화면

- 왼쪽에 슬로건과 서비스 바로가기 메뉴가 있다.
- 서비스 바로가기 네 항목은 보라색이며 선택 시 해당 서비스 카드로 이동한다.
- `포트폴리오 보기`, `프로젝트 문의하기` 버튼은 서비스 바로가기 아래에 있다.
- 회전 안내 문구와 좌우 화살표 아이콘은 제거됐다.
- 홈 전용 배경 이미지는 아래 파일만 사용한다.
  - `public/hero/vizentive-home-bg.png`
- 홈 이미지는 데이터 월에 포함하지 않는다.
- 홈 이미지는 정사각형 1:1 비율, 잘림 없는 `object-fit: contain`, 투명도 50%다.
- 이미지 위치는 PC에서 위로 103px, 모바일에서 위로 30px 이동한다.

## 모바일 홈 및 도넛 배치

- 모바일 슬로건 크기: `2.8rem`
- 모바일 도넛은 고정 좌표로 배치하지 않는다.
- `포트폴리오 보기`, `프로젝트 문의하기` 버튼의 실제 하단을 측정한다.
- 버튼 하단에서 화면 높이의 3%만큼 간격을 둔 다음 도넛을 배치한다.
- 정보 패널과 대분류 이동 버튼도 도넛 위치에 연동한다.
- 관련 함수: `syncMobileTorusPosition()`
- 화면 크기 변경 및 웹폰트 로딩 완료 시 위치를 다시 계산한다.

## 도넛 브라우저 동작

- 마우스 드래그 및 모바일 스와이프로 회전한다.
- 전면이 아닌 이미지를 선택하면 전면으로만 이동한다.
- 최전면 대표 이미지를 선택하면 하부 이미지로 들어간다.
- 최전면 하부 이미지를 선택하면 고해상도 원본 보기로 들어간다.
- 최전면 이미지는 조금 더 크게 표시한다.
- 후면 이미지도 흐리게 만들지 않고 최대한 선명하게 표시한다.
- 대표 이미지 설명은 대분류 상태에서만 표시한다.

## 원본 보기 화면

- 좌우 스와이프 및 화면 양끝 25% 클릭 이동을 지원한다.
- 좌우 화살표, 정보 보기 토글, 확대 슬라이더가 있다.
- 확대 상태와 무관하게 화면 양끝 이동 기능이 동작한다.
- 모바일 핀치 확대와 PC 확대 슬라이더가 연동된다.
- 더블클릭 시 1:1 배율로 돌아간다.
- 정보 패널은 드래그할 수 있다.
- 정보 패널 배경 투명도를 조절할 수 있으며 블러는 사용하지 않는다.
- 조작 버튼은 3초 후 사라지고 동작 시 다시 나타난다.

## 검증 및 로컬 실행 주의사항

- 원본 수정 파일은 `index.html`이다.
- 로컬에서 `dist/index.html`을 보고 있을 수 있으므로 수정 후 반드시 빌드해야 한다.
- 검증 및 빌드 명령:

```powershell
python tools/validate_site.py
```

- 위 명령 실행 후 `index.html`과 `dist/index.html`에 변경이 모두 반영됐는지 확인한다.
- 과거에 원본만 수정하고 `dist`를 빌드하지 않아 화면에서 변경이 보이지 않았던 문제가 있었다. 같은 실수를 반복하지 않는다.
